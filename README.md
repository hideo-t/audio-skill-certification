# audio-skill-certification

音響スキル認定システムは、音響技術者の能力を客観的に評価・認定するWebアプリです。初心者から管理者まで5つのカテゴリで段階的スキルアップを支援。○×形式の問題で効率的学習、80%以上で認定番号発行。業界標準のスキル体系化を実現し、技術者のキャリア形成をサポートします。

## 技術スタック
- HTML5 / CSS3 / Vanilla JS
- Mobile-first responsive design
- Hosted on GitHub Pages
